# Retro Encabulator MCC development room

Added `dev6` as a test room for a seven-section, CENTERLINE-style Retro Encabulator motor-control center. `dev4` and `dev5` remain aliases for the Hall and Rhombus, so neither ID was reused. The new lineup has 90-inch section proportions, continuous top and bottom wireways, vertical wireways, copper bus representation and varied MCC bucket heights. Every bucket door opens; starter, control, PLC and drive compartments have modelled interiors using the project's existing controls, device views and rack units. The setting is a plain electrical room with fluorescent fixtures, conduit, cable tray and a neighbouring enclosure. Portals connect dev6 to dev3 and the Hall, and the Hall station links back to dev6. Rockwell reference dimensions and the visual interpretation are documented in `doc/research/centerline-2100-mcc.md`.

Chrome inspection showed the closed seven-bay lineup and opening control and PLC doors. An early pass exposed interior subassembly doors through the closed bucket faces; replacing those with a breaker backplate removed the stray geometry. The PLC door now reveals its I/O modules and rack units. All five repository checks passed with 211 tests.
