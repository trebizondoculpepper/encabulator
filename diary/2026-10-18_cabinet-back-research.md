# Cabinet-back research and BBC diagnostic terminal prompt

Researched real cabinet construction using Rockwell CENTERLINE and Rittal VX25 manufacturer documents, icotek cable-entry references, Phoenix Contact wiring duct and a period Rittal cabinet photograph. Saved a credited picture pack and reviewed its contact sheet. Wrote a seven-section cabinet-back plan covering service access, bus guards, connections to existing equipment, culling and compatibility with shared game scenes. No cabinet-back implementation was performed.

Logged the owner's BBC Micro Model B diagnostic-terminal idea as `doc/prompts/bbc-micro-diagnostic-terminal.md`. It explicitly reuses the VX3 BBC Micro, Microvitec Cub monitor, disk drive and desk, starts OFF, beeps before loading diagnostics, and connects by ribbon cable to a machine rear interface. No BBC implementation was performed. All new task documents include report return paths.
