# BBC Micro / annunciator diagnostics

## 18 October 2026 — implementation

For the owner and next reviewing agent. Implements the [diagnostic prompt](../prompts/bbc-micro-annunciator-diagnostics.md), developing the [original terminal prompt](../prompts/bbc-micro-diagnostic-terminal.md) and reusing the physical route in the [cabinet-back report](encabulator-cabinet-backs.md). The owner’s final revision replaces the external fourth lamp with internal Neumann Link Controller and Neumann Diagnostics daughterboards on a fixed motherboard. The front remains TEST, ACK and RESET, centred beneath the grid. The separate Automation Control five-card rack is unchanged.

The annunciator endpoint is `mcc.diagnosticEndpoint`: its incoming/station-battery feed, existing internal isolator, control fuse, supply terminal and two healthy/connected diagnostic boards. MAIN DISCONNECT may be off while the endpoint works. The cabinet’s internal isolator starts off in Level0, like other operator controls: turn incoming power on, open DISTRIBUTION, switch ANNUNCIATOR ISOLATOR on, close the door and power the BBC. No new input bindings. Clicking each diagnostic card’s front retention/connection retracts it 20 mm and toggles its own service connection; these mounted cards are not loose throwable exhibits. Their motherboard is fixed.

BBC ROM/loader takes 4.5 seconds, displaying `>CHAIN "DIAG"`; the subsequent logical handshake takes 0.35 seconds and the first diagnostic read 1.5 seconds. The green controller LED flashes at 1 Hz, 50% duty, only after this first valid response. A single restrained controller beep marks each newly established session. BBC power-off, endpoint isolation or either board’s disconnection/failure invalidates the session immediately. Reconnection repeats handshake/read, never the computer boot beep. Steady telemetry updates do neither. Power alone does not imply diagnostics available.

Reusable boot/link state is pure toolkit logic with a read-only online/text interface. Game diagnosis is in `src/game/bbc-machine-diagnostics.ts`, observing the same plant values/fault identities as the PanelView and annunciator. It cannot invoke plant actions. Level0 binds full graph telemetry; Level2 has an explicit limited adapter for actual main/interlock/failure states and directs the player to the supervisor without changing the script. Dev19 has a labelled simulated loopback endpoint, BBC power and endpoint test controls, and the same diagnostic-board component. Imported comparison geometry and procedural baseline share behaviour; a late geometry swap silently transfers boot/session state rather than replaying a beep or disk read; the existing development-only model restriction is preserved.

Leading checks are deterministic and dependency ordered; unresolved upstream causes suppress downstream startup noise. Board/hardware failures precede general startup hints. The page wraps words to 40 columns, with 22 body rows plus the three-line program header. It shows one leading action; secondary fault summaries are bounded.

Audio is original synthesis: a mechanical paired-step seek at the drive and a brief electronic connection beep at the internal controller. Sound cancellation covers link loss, power-off, suspension and disposal, with no replay on resume. Sound provenance is in `CREDITS.md` and the shared audio README. The existing BBC-to-Cub signal and mains cables, floor power box and protected rear data route are reused unchanged.

Browser inspection confirmed the three centred front controls and the two internal daughterboards with the existing isolator. [Cabinet inspection screenshot](images/neumann-diagnostic-cabinet.png). Viewing: `?room=level0&view=annunciator` inspects the centred front. Open its door using a black fastener to inspect the two boards and labelled isolator; `?room=level0&view=annunciator-open` is an explicit development-only open-door inspection start. `?room=dev19&view=boot` starts the imported comparison’s deterministic loopback demonstration. The gallery’s dual computers are comparison exhibits sharing a simulated endpoint, not two physical serial terminals installed in the machine.

Final verification: `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test -- --maxWorkers=2` and `npm run build` all passed; 89 test files, 657 tests. Tests cover both power orders, handshake/read cancellation, immediate session invalidation, reconnect, unchanged healthy updates, off-screen sound cancellation/no replay, silent imported-model transfer, passive controller LED, one connection beep, endpoint isolation with MAIN DISCONNECT off, card connection/failure, dependency-ordered advice, repaired PLC reset, pressure ramp versus fault, nominal state and 40 × 25 limits. Existing annunciator tests now explicitly energise its internal isolator, and expect a dark panel when that isolator is opened. Browser inspection verified the curved diagnostic display, restored centred front and open cabinet. The build retains its existing large-chunk advisory; it succeeds.

Concurrent machine-side rendering/culling changes already present in the shared workspace are included in the final checked snapshot; they are independent of the read-only terminal protocol. The full regression suite covers those changes too.

## 18 October 2026 — green-state fanfare

Level0 now passes the exact green-tier indication (`mcc.steady`) used to draw the machine’s tri-state/stack light into the read-only BBC interface. The computer plays the selected short resynthesized fanfare with light mono case resonance once on entering green, if BBC power is already on. It does not queue an achievement while off or play retrospectively on later power-on. One second without green re-arms it; short flickers cannot repeatedly trigger. Power-off, lost green, suspension and disposal cancel playback; a geometry swap transfers arming state silently. The sound comes from the computer, separate from the internal controller’s connection beep. Level2’s narrative adapter is unchanged. Other audition variants are removed; the listening page retains only the four selected reverberant resynths.
