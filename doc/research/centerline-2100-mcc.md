# CENTERLINE 2100 references for the Retro Encabulator lineup

The video prop is treated as a period Allen-Bradley / Rockwell motor-control center. The scene is a visual interpretation, not a claim that a particular filmed cabinet or electrical design has been identified. Current Rockwell documents establish the long-lived CENTERLINE 2100 cabinet architecture; period styling follows the owner's brief.

Rockwell's [CENTERLINE 2100 selection guide](https://literature.rockwellautomation.com/idc/groups/literature/documents/sg/2100-sg003_-en-p.pdf) gives a standard section envelope of 90 × 20 × 15 inches, with 20-inch depth available, and wider sections for larger equipment. The scene uses 90-inch height, 20-inch depth, 20-inch standard width, and 25- or 30-inch wider incoming, drive and PLC sections.

Rockwell's [MCC procurement specification](https://literature.rockwellautomation.com/idc/groups/literature/documents/sr/2100-sr007_-en-e.pdf) describes continuous six-inch top and bottom horizontal wireways, a separate vertical wireway, and twelve 6.5-inch unit spaces in a standard section. These dimensions set the scene's door grid. Its current finish specification calls for ANSI 49 medium light grey, consistent with the restrained warm grey chosen here.

Rockwell's [joining and splicing instructions](https://literature.rockwellautomation.com/idc/groups/literature/documents/in/2100-in010_-en-p.pdf) show horizontal three-phase bus, bottom ground bus and the top and bottom wireway covers across adjacent sections. The model represents these behind the doors and across the lineup.

Rockwell's [PLC-5 / 1771 system reference](https://support.rockwellautomation.com/cc/okcsFattachCustom/get/675973_14) describes processor and I/O modules in a 1771 chassis. The PLC bay uses period-style CPU, power, digital input/output, analogue input and communications modules, with the project's existing rack-unit views below them. The reused 19-inch rack units are set inside a deliberately wider MCC section; they are visual equipment inside the bay, not MCC buckets.
