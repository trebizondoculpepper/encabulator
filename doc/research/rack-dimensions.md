# Rack dimensions

The racks room (dev3) and `src/scene/rack-equipment.ts` are built to these figures, taken from the EIA-310 standard as summarised by secondary sources and from manufacturers' and distributors' catalogue listings. Where sources disagree, the figure used is noted.

## The 19-inch standard (EIA-310)

| Dimension                   | Figure                                                                                       | Source                                                                                                            |
| --------------------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Rack unit (U)               | 1.75 in (44.45 mm)                                                                           | [Rack unit, Wikipedia](https://en.wikipedia.org/wiki/Rack_unit)                                                   |
| Front panel height          | 1.75n − 1/32 in (1U panel 1 23/32 in, 43.66 mm)                                              | [Rack unit, Wikipedia](https://en.wikipedia.org/wiki/Rack_unit)                                                   |
| Front panel width           | 19 in (482.6 mm)                                                                             | [19-inch rack, Wikipedia](https://en.wikipedia.org/wiki/19-inch_rack)                                             |
| Hole centres, left to right | 18 5/16 in (465.1 mm)                                                                        | [RackSolutions: What is EIA-310](https://help.racksolutions.com/hc/en-us/articles/10431608060692-What-is-EIA-310) |
| Opening between rails       | 17.72 in (450 mm) minimum                                                                    | [RackSolutions: What is EIA-310](https://help.racksolutions.com/hc/en-us/articles/10431608060692-What-is-EIA-310) |
| Vertical hole pitch         | 1/2, 5/8, 5/8 in, repeating each unit; a unit's boundary falls in the middle of a 1/2 in gap | [Rack unit, Wikipedia](https://en.wikipedia.org/wiki/Rack_unit)                                                   |
| Holes                       | 3/8 in square, for cage nuts                                                                 | Common practice                                                                                                   |
